# Coolify deployment

This repo deploys as **two Coolify applications** from the same git repository:

| Coolify app | Dockerfile | Port |
|-------------|------------|------|
| Website | `/Dockerfile.website` | `3000` |
| Applications bot | `/Dockerfile.bot` | `8787` |
