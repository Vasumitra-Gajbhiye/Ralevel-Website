# Cloudflare R2 (file uploads)

**Tier 3. Ask the owner before setting this up.** R2 stores files people upload: attachments on application forms (`R2_FORMS_*`) and resource submissions (`R2_BUCKET_NAME`, `R2_PUBLIC_URL`). Without it, those uploads fail with "R2 is not configured". Forms without file fields still work.

There are two ways to get access:

- **Your own Cloudflare account** (preferred, if you can). Cloudflare may ask for a payment method to turn on R2, even though small usage is free.
- **A dev bucket from the owner.** If you can't use your own account, the owner can give you a token that only works on a development bucket. You'll get it through a one-time secure link, never in chat.

## Set up with your own account

1. In the [Cloudflare dashboard](https://dash.cloudflare.com), open **R2** and enable it.
2. Create two buckets, e.g. `ralevel-dev-resources` and `ralevel-dev-forms`.
3. For each bucket: **Settings → Public access → R2.dev subdomain → Allow**, and copy the public URL (`https://pub-….r2.dev`).
4. **R2 → Manage API tokens → Create API token**: permission **Object Read & Write**, limited to **those two buckets**. Copy the **Access Key ID** and **Secret Access Key**. Your **Account ID** is shown on the R2 overview page.
5. Add everything to `apps/website/.env.local` and restart `pnpm dev`:

   ```bash
   R2_ACCOUNT_ID=...
   R2_ACCESS_KEY_ID=...
   R2_SECRET_ACCESS_KEY=...
   R2_BUCKET_NAME=ralevel-dev-resources
   R2_PUBLIC_URL=https://pub-....r2.dev
   R2_FORMS_BUCKET_NAME=ralevel-dev-forms
   R2_FORMS_PUBLIC_URL=https://pub-....r2.dev
   ```

✅ **You should now see** a file you attach to an application form (or a resource submission) appear in your bucket in the Cloudflare dashboard, and its link open in the browser.
